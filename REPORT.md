## Программирование мобильных устройств — цель

Закрепить синтаксис Kotlin, безопасную работу с nullable-значениями, обработку коллекций функциями высшего порядка и асинхронное выполнение задач с корутинами.

<a id="part1"></a>
## Программирование мобильных устройств — часть 1

### Синтаксис и null-безопасность

| Задача | Решение | Пример ожидаемого результата |
|:---|:---|:---|
| Приветствие | Строковая интерполяция и `age + 10` | `greetUser("Анна", 25)` → «Привет, Анна! Через 10 лет тебе будет 35 лет.» |
| Время года | `when` с диапазонами месяцев | `getSeason(3)` → «Весна»; 13 → «Некорректный месяц» |
| Факториал | `tailrec` с накопителем | 5 → 120; 0 → 1; отрицательное число → -1 |
| Парсинг числа | `str?.toIntOrNull()` | «123» → 123; «abc» и `null` → `null` |
| Фильтрация | `filterNotNull().map { it * 2 }` | `[1, null, 3, null, 5]` → `[2, 6, 10]` |

Факториал возвращается как `Long`: точный результат помещается в этот тип для n от 0 до 20. Текущая функция не проверяет переполнение при больших n.

## Программирование мобильных устройств — часть 2

### Коллекции и корутины

| Задача | Решение | Ожидаемое поведение |
|:---|:---|:---|
| Средний возраст | `map` и `average` | Для пустого списка — 0.0 |
| Группировка слов | `groupBy` и `uppercaseChar` | Пустые и состоящие из пробелов строки пропускаются |
| Длинное слово | `maxByOrNull` | Для пустого списка — `null` |
| Асинхронная задержка | `println`, `delay`, `println` | Сначала сообщение, затем задержка, затем «Готово!» |
| Конкурентные задачи | `coroutineScope`, `async`, `select` и `onAwait` | Задержки 1, 2 и 3 секунды; каждый результат печатается при получении |

Ожидающие результаты выбираются через `select`: готовая задача удаляется из списка ожидания. Это устраняет последовательное ожидание заранее заданного списка `await`, которое может скрыть более раннее завершение другой задачи. После получения результатов вызывается `await` для всех созданных задач; функция возвращает список в порядке обработки завершений.

## Программирование мобильных устройств — контрольные вопросы

<details>
<summary>1. В чём разница между val и var?</summary>

`val` запрещает повторное присваивание переменной, `var` допускает его. При этом `val` не делает сам объект неизменяемым: содержимое изменяемой коллекции, хранящейся в `val`, можно менять.

</details>

<details>
<summary>2. Что такое null-безопасность и как она реализована в Kotlin?</summary>

Типы разделяются на допускающие `null`, например `String?`, и не допускающие его, например `String`. Оператор `?.` выполняет безопасный вызов, `?:` задаёт запасное значение, а `!!` выбрасывает исключение, если значение равно `null`. В задаче 2.1 используется `str?.toIntOrNull()`.

</details>

<details>
<summary>3. Что такое tailrec и когда его следует использовать?</summary>

`tailrec` позволяет компилятору заменить подходящую хвостовую рекурсию циклом. Рекурсивный вызов должен быть последней операцией соответствующей ветки. Такой подход полезен для рекурсивных алгоритмов с накопителем и позволяет не наращивать стек на каждом шаге. Оптимизация не предотвращает арифметическое переполнение.

</details>

<details>
<summary>4. Чем filter отличается от filterNotNull?</summary>

`filter` отбирает элементы по переданному условию. `filterNotNull` удаляет `null` и возвращает коллекцию с non-nullable-типом элементов. В работе после удаления `null` значения удваиваются через `map`.

</details>

<details>
<summary>5. Что такое функции высшего порядка? Приведите пример.</summary>

Такая функция принимает другую функцию как аргумент или возвращает функцию. Пример: `map` принимает преобразование для каждого элемента.

```kotlin
val doubled = listOf(1, 3, 5).map { it * 2 }
```

Результат — `[2, 6, 10]`.

</details>

<details>
<summary>6. Что такое корутины и зачем они нужны?</summary>

Корутины позволяют организовать асинхронную работу с приостановкой и возобновлением выполнения. Их используют для ожидания ввода-вывода и конкурентного выполнения задач. `delay` приостанавливает корутину, не блокируя поток на время ожидания. Конкурентность не обязательно означает одновременное выполнение на разных ядрах.

</details>

<details>
<summary>7. В чём разница между launch и async?</summary>

`launch` возвращает `Job` и используется для работы без отдельного возвращаемого результата. `async` возвращает `Deferred<T>`, результат которого получают через `await`. Для ожидания завершения `Job` применяется `join`.

</details>

<details>
<summary>8. Что такое suspend-функция?</summary>

Функция с модификатором `suspend` может вызывать приостанавливаемые операции и вызывается из suspend-контекста. Сам модификатор не запускает корутину, не переключает поток и не гарантирует отсутствие блокирующего кода внутри функции.

</details>

<details>
<summary>9. Как работает groupBy в Kotlin?</summary>

`groupBy` вычисляет ключ для каждого элемента и собирает элементы с одинаковым ключом в `Map<K, List<T>>`. В работе ключ — первая буква слова в верхнем регистре; пустые строки заранее отфильтрованы.

</details>

<details>
<summary>10. Что такое data class и зачем он нужен?</summary>

`data class` удобен для моделей данных. Для свойств первичного конструктора компилятор генерирует `equals`, `hashCode`, `toString`, `copy` и `componentN`. В работе модель `Person` содержит имя и возраст. Метод `copy` создаёт поверхностную, а не глубокую копию.

</details>

<a id="reflection"></a>
## Программирование мобильных устройств — разбор решений

- Nullable-строки обрабатываются без `!!`: отсутствие числа выражается результатом `null`.
- Для пустого списка людей предусмотрен отдельный результат 0.0.
- `tailrec` решает вопрос глубины рекурсии, но не ограниченного диапазона `Long`.
- Демонстрация в консоли отделена от тестов с проверками.
- Порядок завершения корутин не подменяется порядком объявления задач.
