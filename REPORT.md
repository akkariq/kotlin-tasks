### 3. Ответы на контрольные вопросы

#### 1. В чем разница между `val` и `var`?
- `val` (value) объявляет неизменяемую ссылку (read-only), значение которой инициализируется однократно.
- `var` (variable) объявляет мутабельную переменную, значение которой можно перезаписывать многократно.

#### 2. Как работает null-безопасность в Kotlin?
Kotlin разделяет типы на nullable (`String?`) и non-nullable (`String`). Прямой вызов методов у nullable-типов блокируется компилятором. Для работы с ними используются:
- `?.` (безопасный вызов) — выполняет метод, если объект не `null`, иначе возвращает `null`.
- `?:` (Элвис-оператор) — задает значение по умолчанию, если выражение слева вернуло `null`.
- `!!` (non-null assertion) — утверждение, что значение не `null`; при `null` выбрасывает исключение `NullPointerException`.

#### 3. Что такое `tailrec` и как он работает?
Модификатор `tailrec` указывает компилятору оптимизировать рекурсивную функцию в плоский итеративный цикл (байт-код без создания новых кадров стека). Это исключает риск падения с `StackOverflowError`. Обязательное условие: рекурсивный вызов должен быть терминальной операцией в теле функции.

#### 4. В чем разница между `filter` и `filterNotNull`?
- `filter` принимает предикат `(T) -> Boolean` и фильтрует элементы по условию, сохраняя исходный nullable-тип (`List<T?>`).
- `filterNotNull` удаляет строго `null`-элементы и сужает тип результирующего списка с `List<T?>` до строгого `List<T>`.

#### 5. В чем разница между корутинными билдерами `launch` и `async`?
- `launch` запускает корутину без возврата значения и возвращает дескриптор `Job` для управления жизненным циклом задачи.
- `async` запускает асинхронное вычисление и возвращает `Deferred<T>`, позволяющий получить результат вызова через метод `.await()`.

#### 6. Что такое `suspend`-функция?
Это приостанавливаемая функция, которая может временно остановить свое выполнение без блокировки системного потока (non-blocking) и возобновить его позже. Вызывается только из других `suspend`-функций или из контекста корутин.

#### 7. Как работает `groupBy` в Kotlin?
Функция `groupBy` принимает лямбду-селектор ключа и преобразует коллекцию в `Map<K, List<T>>`. Элементы с одинаковым вычисленным ключом объединяются в один список под этим ключом.

#### 8. Что такое `data class` и какие методы в нем генерируются автоматически?
`data class` предназначен исключительно для хранения данных. Компилятор автоматически генерирует для его первичных свойств методы:
- `equals()` и `hashCode()` — для сравнения объектов по значениям;
- `toString()` — для читаемого строкового представления;
- `copy()` — для создания копии объекта с частичной заменой полей;
- `componentN()` — для деструктурирующего присваивания.

#### 9. Что такое `runBlocking` и для чего он используется?
`runBlocking` — корутинный билдер, который блокирует текущий системный поток до тех пор, пока корутина внутри него и все ее дочерние задачи не завершат работу. Используется преимущественно в функции `main()` и unit-тестах для сопряжения синхронного кода с асинхронными вызовами.

#### 10. В чем отличие `Iterable` от `Sequence`?
- `Iterable` вычисляет шаги жадно (eager evaluation): каждая промежуточная операция (`map`, `filter`) сразу создает новую промежуточную коллекцию в оперативной памяти.
- `Sequence` производит ленивые вычисления (lazy evaluation): элементы обрабатываются поочередно по всей цепочке вызовов только при наступлении терминальной операции (`toList()`, `first()`), что экономит память на больших объемах данных.
